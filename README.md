# 청주농업고등학교 둘레길 사진 게시판

청주농업고등학교의 아름다운 14개 둘레길을 소개하고, 각 둘레길별로 사진을 촬영하여 자유롭게 업로드하고 공유할 수 있는 오프라인 실행형 웹 프로그램입니다.

파이썬이나 Node.js 같은 복잡한 서버 설정을 설치할 필요 없이, 브라우저가 지원하는 로컬 데이터베이스인 **IndexedDB** 기술을 사용하여 브라우저에서 `index.html` 파일을 여는 것만으로 데이터를 영구 저장하고 사진 게시판을 바로 활용할 수 있습니다.

---

## 📂 파일 구조

- **`index.html`**: 웹 애플리케이션의 뼈대와 디자인 레이아웃 (Tailwind CSS 기반)
- **`app.js`**: 데이터 처리(IndexedDB), 이미지 크기 축소 및 압축, 화면 전환(SPA) 로직
- **`README.md`**: 본 설명서 파일

---

## 🚀 실행 방법

별도의 서버 설치 작업이 필요 없습니다.
1. 이 폴더에 있는 **`index.html`** 파일을 마우스로 더블 클릭합니다.
2. 기본 웹 브라우저(Google Chrome, Microsoft Edge, Safari 등)가 실행되며 프로그램이 열립니다.
3. 둘레길 번호나 카드를 선택하여 해당 코스의 사진 게시판으로 바로 진입할 수 있습니다.

---

## ✨ 핵심 기능

1. **서버가 필요 없는 로컬 영구 저장 (IndexedDB)**
   - 브라우저 고유의 로컬 데이터베이스 공간을 활용하므로 컴퓨터를 껐다 켜거나 브라우저를 닫아도 올린 사진이 유지됩니다.
   - 단, 브라우저의 '쿠키 및 기타 사이트 데이터 삭제' 또는 '인터넷 기록 삭제'를 진행할 경우 데이터가 지워질 수 있으니 주의해 주세요.

2. **자동 사진 용량 축소 및 압축 (Canvas API)**
   - 사진 파일 업로드 시 브라우저 용량 제한과 속도 저하를 방지하기 위해 가로 1024px 크기로 비율을 유지하며 고속으로 압축(JPEG, 0.8 품질)하여 데이터베이스에 저장합니다.
   - 이로 인해 용량이 큰 스마트폰 고화질 사진도 무리 없이 바로 저장하고 감상할 수 있습니다.

3. **둘레길별 사진 수 실시간 연동**
   - 첫 메인 화면에서 14개 코스의 목록을 볼 수 있고, 각 코스마다 현재 사진이 몇 장 업로드되었는지 실시간 개수가 연동되어 나타납니다.

4. **비밀번호 기반의 삭제 권한 관리**
   - 게시물을 등록할 때 사용자 본인이 설정한 비밀번호를 통해 불필요하거나 잘못 올린 사진을 쉽게 삭제할 수 있습니다.

5. **라이트박스 돋보기 뷰어**
   - 등록된 사진을 클릭하면 어두운 배경과 함께 사진을 크게 확대하여 볼 수 있는 세련된 UI의 라이트박스 기능이 내장되어 있습니다.

## 🌲 둘레길 코스 안내 (14개 코스)

1. **첫걸음길**: 청농인으로서의 첫 발걸음을 딛는 설렘이 가득한 길
2. **100주년길**: 청주농업고등학교의 깊은 역사와 전통을 기념하는 길
3. **독립운동길**: 나라를 위해 헌신한 선배님들의 숭고한 나라사랑 정신을 기리는 길
4. **농원관길**: 배움과 도전이 살아 숨 쉬는 농원관 주변의 길
5. **과수원길**: 계절마다 달콤한 열매가 맺히는 과수원의 풍요로움을 느끼는 길
6. **개나리길**: 봄이면 노란 개나리가 흐드러지게 피어나는 아름다운 길
7. **산목련길**: 하얀 산목련 꽃망울이 우아하게 반겨주는 길
8. **숲속오솔길**: 도심 속 울창한 나무들이 내뿜는 피톤치드를 마시며 걷는 힐링 길
9. **노랑단풍길**: 가을철 황금빛 단풍 터널이 장관을 이루는 낭만적인 길
10. **소나무길**: 사계절 푸른 소나무처럼 변함없는 기상을 배울 수 있는 길
11. **벚꽃길**: 봄바람에 휘날리는 벚꽃 잎이 눈부신 화사한 길
12. **논두렁길**: 벼가 자라나는 들판의 정겨움과 생명력을 가까이서 느끼는 길
13. **해솔길**: 소나무 사이로 비치는 맑은 햇살을 맞으며 걷는 길
14. **미래농업길**: 스마트 농업과 첨단 생명산업을 이끌어갈 청농의 미래를 꿈꾸는 길

## 🛠️ 추후 협업형(서버 연동) 서비스로의 확장 방법

이 프로그램은 교육용 및 데모용으로 단일 브라우저 내부에서만 저장되는 구조입니다. 만약 실제로 학교 전교생과 선생님들이 각자 자신의 폰으로 사진을 올려 실시간 공유하는 서비스로 전환하고 싶다면 아래 단계가 필요합니다:

1. **웹 서버 구축**: Python (Flask/FastAPI) 또는 Node.js (Express) 서버를 구성합니다.
2. **데이터베이스 이전**: SQLite 또는 MySQL 데이터베이스를 서버에 설치하여 브라우저의 `IndexedDB`에 있는 데이터를 원격 서버 DB로 교체합니다.
3. **API 연동**: `app.js`에서 IndexedDB에 `addPost` / `getAllPosts` 하던 부분을 `fetch('/api/posts', { method: 'POST' ... })` 형태로 서버 통신 API로 교체합니다.
4. **웹 호스팅 및 도메인**: 카페24, AWS, 닷홈 등의 클라우드나 학교 전용 서버컴퓨터에 웹 소스를 올려 누구나 도메인 주소로 접속하도록 배포합니다.
